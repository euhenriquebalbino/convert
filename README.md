# 💱 Convert

Aplicação web para converter valores de dólar americano, euro e libra esterlina em reais (BRL), com resultado formatado no padrão brasileiro.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎨 Layout

O projeto apresenta uma interface objetiva para conversão de moedas, com formulário centralizado, campos de valor e moeda, além da exibição do resultado após o envio.

## 📂 Estrutura do projeto

.
├── index.html
├── style.css
├── main.js
└── img/
    ├── bg.png
    └── ícones e logomarca

## 🧩 Funcionalidades

- Conversão de dólar, euro e libra para reais
- Restrição do campo de valor a caracteres numéricos
- Formatação monetária no padrão `pt-BR`
- Exibição da cotação e do valor convertido

## 📖 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei:

- Manipulação do DOM com JavaScript
- Eventos de formulário e validação de entradas
- Estruturas condicionais com `switch`
- Formatação de números com `toLocaleString`
